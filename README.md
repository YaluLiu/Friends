# Friends（老友记）中文台词

中文版《老友记》台词，实在太精彩了，就记录下来研究下台词。

## 目录说明

`S01` 至 `S10` 分别收录《Friends》（《老友记》）第一季至第十季的中文台词，每季按集保存。

## 后续整理方向

后续计划以 `S01` 的现有格式为参考，逐步统一所有季的台词格式，在每句台词前标注角色名，方便辨认说话的角色。例如：

```text
Monica:没什么可说的。只不过是我的同事而已。
Joey:少来了，你和那个人出去约会，他一定是有什么问题！
```

以上是后续整理目标，目前各季的格式尚未全部统一。
